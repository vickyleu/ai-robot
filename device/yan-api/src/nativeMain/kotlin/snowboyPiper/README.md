# SnowboyPiper语音识别与合成系统

本项目结合Snowboy唤醒词检测与Piper语音合成，为资源受限设备（如树莓派3B）提供轻量级的语音交互解决方案。

## 优化清单与改进

针对树莓派3B这类资源受限设备，我们进行了以下优化：

### 1. 内存与资源管理

- **单例预热机制**：通过`AudioProcessingResourceManager`预先加载常用配置，减少运行时资源创建延迟
- **缓冲区池化系统**：实现了`AudioBufferManager`池化机制，减少频繁内存分配与碎片化
- **延迟组件初始化**：非必要资源采用懒加载模式，减少初始内存占用
- **资源生命周期管理**：统一添加资源清理钩子，确保程序正常退出时释放资源

### 2. 音频处理优化

- **处理链调整**：简化音频处理流程，SpeexDSP和RNNoise特性按需启用
- **参数调优**：
  - VAD阈值降至0.08f，提高检测灵敏度
  - 降噪强度适度调整，平衡降噪效果与计算开销
  - 回声消除参数适配树莓派扬声器特性

### 3. 代码结构改进

- **统一包结构**：解决了多个包路径冲突问题
- **接口重构**：修改AudioPlayer接口的release方法，解决方法名冲突
- **编译优化**：移除不必要的依赖，减少编译时间和二进制文件大小

### 4. 性能诊断工具

- **添加详细日志**：关键处理节点增加跟踪日志，便于定位性能瓶颈
- **资源使用统计**：引入简单的性能计数器，监控内存使用和处理延迟

## 使用注意事项

1. 该版本已针对树莓派3B进行了优化，可能需要针对其他硬件平台再次调整参数
2. 使用前请确保已安装ALSA和PortAudio依赖库
3. 预热功能可以加快系统初次响应，但会稍微延长启动时间
4. 为获得最佳性能，建议使用16kHz采样率，降低音频回放和处理的延迟

## 构建与运行

```bash
# 构建项目
./gradlew :device:yan-api:linkReleaseExecutableLinuxArm32Hfp

# 创建Debian包
./gradlew :device:yan-api:distDeb

# 安装到远程设备
./gradlew :device:yan-api:installDeb
```

## 性能参考数据（树莓派3B）

- 内存使用: ~40MB
- CPU使用: ~15-25%
- 唤醒词检测延迟: <200ms
- 语音合成延迟: <500ms（短句）
