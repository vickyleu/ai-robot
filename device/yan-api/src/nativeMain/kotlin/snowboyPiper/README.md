# VoskPiper语音识别与合成系统

本项目结合Vosk语音识别（含关键词检测）与Piper语音合成，为资源受限设备（如树莓派3B）提供轻量级的语音交互解决方案。

## 优化清单与改进

针对树莓派3B这类资源受限设备，我们进行了以下优化：

### 1. 内存与资源管理

- **单例预热机制**：通过`AudioProcessingResourceManager`预先加载常用配置，减少运行时资源创建延迟
- **缓冲区池化系统**：实现了`AudioBufferManager`池化机制，减少频繁内存分配与碎片化
- **延迟组件初始化**：非必要资源采用懒加载模式，减少初始内存占用
- **资源生命周期管理**：统一添加资源清理钩子，确保程序正常退出时释放资源

### 2. 音频处理优化

- **处理链调整**：简化音频处理流程，SpeexDSP和RNNoise特性按需启用
- **参数调优**：
  - VAD阈值降至0.08f，提高检测灵敏度
  - 降噪强度适度调整，平衡降噪效果与计算开销
  - 回声消除参数适配树莓派扬声器特性
- **采样率转换**：使用高质量的SoxrSingleton从48kHz转到16kHz，提供更好的识别输入
  - 替换了简单降采样为专业的SoX重采样库
  - 避免采样率转换导致的信号失真和噪声引入
- **增强型音频分析器**：新增了EnhancedAudioAnalyzer实现更精确的语音活动检测
  - 结合能量、过零率和语音概率多维特征进行检测
  - 自适应噪声门限，根据环境噪声自动调整
  - 智能增益控制，保持语音在最佳音量范围
- **环境自适应处理**：实现了环境感知音频处理
  - 实时检测安静、正常、嘈杂和混响四种环境类型
  - 根据环境类型自动调整降噪、回声消除和增益参数
  - 避免环境变化导致的频繁参数波动

### 3. 回声消除增强

- **树莓派专用配置文件**：针对树莓派扬声器特性优化回声消除参数
  - 增强回声抑制级别至-40dB以应对小型扬声器的高回声特性
  - 语音状态下回声抑制增强至-50dB确保清晰对话
  - 精细的增益控制参数避免回声放大
- **自适应环境回声处理**：根据检测到的环境类型自动调整回声参数
  - 混响环境下应用最强回声抑制
  - 安静环境下降低回声抑制以保留语音自然度
  - 嘈杂环境下平衡降噪和回声抑制以提高信噪比

### 4. 代码结构改进

- **统一包结构**：解决了多个包路径冲突问题
- **接口重构**：修改AudioPlayer接口的release方法，解决方法名冲突
- **编译优化**：移除不必要的依赖，减少编译时间和二进制文件大小
- **识别引擎升级**：从Snowboy模型识别更改为Vosk语音识别
  - 使用`vosk_recognizer_set_words`启用词级别识别
  - 使用`vosk_recognizer_set_grm`设置关键词语法
  - 使用JSON解析提取识别结果
  - 支持灵活的关键词配置与动态更新

### 5. 性能诊断工具

- **添加详细日志**：关键处理节点增加跟踪日志，便于定位性能瓶颈
- **资源使用统计**：引入简单的性能计数器，监控内存使用和处理延迟
- **状态报告**：添加了音频分析器和SpeexDSP处理器的状态报告功能
  - 实时监控能量、噪声基线和环境类型
  - 跟踪处理器配置和性能指标
  - 便于调试和性能优化

## 使用注意

- **依赖项安装**：首次运行前请确保已安装Vosk模型和Piper TTS模型

## Vosk关键词检测配置说明

Vosk关键词检测系统提供了灵活的配置选项，支持以下特性：

1. **关键词设置**：
   - 通过`setKeywords`方法可动态设置多个关键词
   - 支持中文、英文等多语言关键词
   - 例如：`voskDetector.setKeywords(listOf("你好", "小度", "嗨"))`

2. **词级别识别**：
   - 使用`enableWordRecognition`启用词级别识别
   - 可获取每个词的时间戳和置信度信息
   - 有助于实现更精准的关键词触发逻辑

3. **灵敏度调节**：
   - 通过能量阈值和置信度阈值可调整检测灵敏度
   - 在`processAudioInternal`中可配置能量门限
   - 在`processRecognitionResult`中可过滤低置信度结果

4. **采样率适配**：
   - 自动将PortAudio的48kHz音频转换为Vosk要求的16kHz
   - 使用高质量SoxrSingleton重采样，而非简单降采样
   - 保证识别质量的同时优化性能

## 音频增强配置

系统提供了丰富的音频增强选项，可通过以下方式配置：

1. **环境类型配置**：
   - 可选配置文件：`raspberry_pi`、`quiet_environment`、`noisy_environment`
   - 使用方法：`speexDsp.initialize(deviceProfile = "raspberry_pi")`
   - 每种配置均针对特定环境优化了回声、噪声和增益参数

2. **自适应处理**：
   - 默认启用环境自适应处理，可根据需要禁用：
   - `speexDsp.setAdaptiveProcessingEnabled(false)`
   - 启用时会自动根据环境噪声调整参数

3. **手动参数调整**：
   - 降噪级别：`speexDsp.setDenoiseLevel(5)` (0-10)
   - 回声抑制：`speexDsp.setEchoSuppress(-35)` (-60到-10，dB)
   - 增益控制：`speexDsp.setAgcLevel(15000)` (目标电平)

4. **增强型音频分析器**：
   - 可配置不同的检测阈值以适应不同场景
   - 支持自适应噪声门限，减少误触发
   - 提供详细的状态报告用于监控和调试

## 资源路径配置

默认资源路径配置如下：
- Vosk模型: `/usr/local/share/vosk/model`
- Piper TTS模型: `/usr/local/share/piper/models/zh_CN-xiaoyan.onnx`
- 声音文件: `resources/sounds/`

可通过配置文件或命令行参数覆盖默认路径。
