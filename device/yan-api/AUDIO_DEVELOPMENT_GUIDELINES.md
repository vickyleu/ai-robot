## 核心原则

### 🚫 严格禁止
- **不要搞脚本** - 所有问题必须在代码层面解决
- **不要删除录音后播放确认步骤** - 这是必要的功能验证机制
- **不准回避问题** - 直面问题并彻底解决，不允许绕过或临时方案
- **不要搞兼容性别名** - 每个配置都要明确，不要模糊的向后兼容
- **不要手动实现音频处理** - 优先使用第三方库（SOXR、WebRTC等）

### ✅ 必须遵循

#### 音频配置管理
- **采样率和声道数明确** - 是1就是1，是2就是2，不存在模糊配置
- **集中配置定义** - 在`AudioDefaults`中定义每种工具的采样率（Piper、WebRTC、输入、输出）
- **不要到处写死参数** - 避免硬编码采样率和声道数

#### 音频流规范
- **输入流：双声道** - 硬件设备输入为双声道
- **输出流：双声道** - 硬件设备输出为双声道
- **参数携带** - 每个音频处理步骤携带采样率和声道参数，防止前后转换不对应

#### 转换逻辑
- **条件转换** - 检查参数是否相同，不相同才转换，相同则跳过
- **完整衔接** - 确保所有转换步骤能够正确衔接，从输入到输出
- **冗余消除** - 仔细检查所有步骤，移除不必要的处理

#### 错误处理
- **崩溃必须修复** - 不允许另辟蹊径的逃避方式
- **根本原因解决** - 找到并修复问题的根本原因
- **第三方库优先** - 使用成熟的第三方库而不是自己实现

## 具体实现要求

### 音频处理流程
```
输入设备(16kHz/2ch) → WebRTC APM(16kHz/1ch) → 输出设备(48kHz/2ch)
```

### 配置结构
```kotlin
object AudioDefaults {
    // 硬件设备
    const val INPUT_DEVICE_SAMPLE_RATE = 16000
    const val INPUT_DEVICE_CHANNELS = 2
    const val OUTPUT_DEVICE_SAMPLE_RATE = 48000
    const val OUTPUT_DEVICE_CHANNELS = 2
    
    // WebRTC APM
    const val WEBRTC_APM_SAMPLE_RATE = 16000
    const val WEBRTC_APM_CHANNELS = 1
    
    // Piper TTS
    const val PIPER_TTS_SAMPLE_RATE = 22050
    const val PIPER_TTS_CHANNELS = 1
}
```

### 函数签名标准
```kotlin
fun processAudio(
    audioData: ShortArray,
    inputSampleRate: Int,
    inputChannels: Int,
    outputSampleRate: Int,
    outputChannels: Int
): ShortArray
```

### 转换检查模式
```kotlin
if (inputSampleRate != targetSampleRate) {
    // 执行重采样
} else {
    // 跳过重采样
}

if (inputChannels != targetChannels) {
    // 执行声道转换
} else {
    // 跳过声道转换
}
```

## 质量标准

### 代码质量
- **清晰明确** - 每个步骤的目的和参数都要明确
- **无冗余** - 移除不必要的处理步骤
- **可追踪** - 详细的日志记录每个转换步骤

### 功能完整性
- **录音播放确认** - 必须保留且正常工作
- **音频质量** - 确保整个处理链路音质无损
- **参数正确性** - 所有采样率和声道转换都要精确

### 稳定性
- **无崩溃** - 系统必须稳定运行
- **异常处理** - 完善的错误处理和恢复机制
- **资源管理** - 正确的内存和资源释放

## 调试和验证

### 音频文件验证
- 保存原始录音：`/tmp/raw_recording.raw`
- 保存播放音频：`/tmp/playback_audio.raw`
- 使用`aplay`命令验证音频质量

### 日志验证
- 记录每个转换步骤的输入输出参数
- 记录音频振幅变化
- 记录处理时间和性能

### 功能验证
- 录音后必须能听到清晰的播放确认
- 语音识别必须正常工作
- 系统长时间运行不崩溃
